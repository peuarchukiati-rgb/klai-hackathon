# klai

> Headless wellness platform · agent-to-agent ready
>
> ดูแลสุขภาพและเวลาของคุณผ่าน ChatGPT/Claude — โดยไม่ต้องเปิดแอปใหม่

## What this is

**Concept:** klai เชื่อมข้อมูลจากมือถือ + IoT health devices ของผู้ใช้ เข้ากับ AI agent ที่ผู้ใช้ใช้อยู่แล้ว (ChatGPT, Claude, etc.)

AI agent ทำหน้าที่ 2 อย่าง:
1. **Wellness planner** — วิเคราะห์ข้อมูล + แนะนำ + วาง plan
2. **Routine task assistant** — สร้าง `.md` template ลดเวลางานประจำ → ผู้ใช้มีเวลาดูแลตัวเองมากขึ้น

**ทำไม headless?** — ผู้ใช้ไม่ต้องเรียนรู้ UI ใหม่ ใช้ผ่าน AI ที่ใช้อยู่แล้ว ผลลัพธ์เป็น `.md` ที่ paste ลง Notion/Obsidian ได้ทันที

## Why this matters

klai is a proof-of-work repo for **agent-first product design**: the app is not the main interface. The user's existing AI agent becomes the interface, and the durable output is Markdown that can move into Notion, Obsidian, work docs, or another agent session.

```text
Health + routine context
→ agent-readable API / samples
→ AI conversation surface
→ Markdown output
→ user action outside the app
```

**What it proves:** useful AI products can be headless; the agent can be the interface and Markdown can be the durable output.

## ทุกอย่าง mock — ไม่มี backend จริง

ตอนนี้:
- ข้อมูลสุขภาพ → mock JSON ใน `public/data/`
- API endpoints → แสดงใน `api.html` เป็น docs (ยังไม่ทำงานจริง)
- Demo chat → hardcoded scenario

ของจริงเฟสต่อไป:
- Real OAuth กับ Apple Health / Garmin / Fitbit
- Hosted API (Cloudflare Workers / Vercel Edge)
- MCP server package `@klai/mcp-server`

## Run locally

```bash
# preview site
npm run dev
# → http://localhost:3000
```

ไม่ต้องติดตั้งอะไรเพิ่ม — เป็น static HTML + Tailwind/Alpine CDN

## Generate ภาพประกอบ (OpenAI)

```bash
# 1. ใส่ key ใน .env.local
OPENAI_API_KEY=sk-...

# 2. รันสคริปต์
npm run gen-images

# หรือ generate เฉพาะ hero
npm run gen-images:hero

# หรือใช้ dall-e-3 แทน gpt-image-1
npm run gen-images:dalle3
```

ภาพจะ save ลง `public/images/` → reload หน้าเว็บภาพจะโผล่อัตโนมัติ

## Deploy

เป็น static site → ลากโฟลเดอร์ `public/` ไป:
- Vercel: `vercel --prod`
- Netlify: drag-drop
- Cloudflare Pages: connect repo
- หรือ GitHub Pages

## Stack

- Pure HTML + Tailwind CSS (CDN)
- Alpine.js สำหรับ interactivity เล็กๆ
- marked.js สำหรับ render markdown
- ไม่มี build step, ไม่มี node_modules ที่ต้องติด
