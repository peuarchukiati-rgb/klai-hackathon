Authentication

ใช้ Bearer token ใน header ทุก request — get key จาก Connect dashboard

# Header ที่ต้องส่ง
Authorization: Bearer klai_sk_xxxxxxxxxxxxxx
Content-Type: application/json
Scopes: health:read · tasks:read · md:generate

Endpoints

GET /v1/health/summary

สรุปข้อมูลสุขภาพช่วงเวลาที่กำหนด — average sleep, HR, HRV, steps, stress

// Request
GET /v1/health/summary?from=2026-05-01&to=2026-05-07

// Response 200
{
  "avgSleepHours": 6.1,
  "avgSteps": 5847,
  "avgRestingHR": 68,
  "avgHRV": 38,
  "avgStressScore": 64,
  "insights": [...]
}
GET /v1/health/daily

ข้อมูลรายวัน — sleep stages, HR zones, workouts, mood

// Request
GET /v1/health/daily?date=2026-05-07

// Response 200
{
  "date": "2026-05-07",
  "sleepHours": 5.8,
  "deepSleepMin": 50,
  "steps": 5110,
  "hrv": 36,
  "mood": "tired"
}
GET /v1/tasks/routine

งานประจำที่ klai detect ได้ — เพื่อให้ AI เลือกได้ว่าจะ automate ตัวไหน

// Response 200
[
  {
    "id": "rt_001",
    "title": "Daily standup notes",
    "frequency": "daily",
    "avgMinutesPerDay": 15,
    "automatable": true
  },
  ...
]
POST /v1/plan/wellness

สร้าง wellness plan — return Markdown ที่ paste ใส่ Notion ได้ทันที

// Request body
{
  "horizon": "7d",
  "focus": "sleep"
}

// Response 200
{
  "format": "markdown",
  "filename": "wellness-plan.md",
  "content": "# Wellness Plan...",
  "validUntil": "2026-05-15"
}
POST /v1/md/generate

สร้าง .md template สำหรับงานประจำ — ปรับตาม health context อัตโนมัติ

// Request body
{
  "taskId": "rt_001",
  "context": { "date": "2026-05-09" }
}

// Response 200 → daily-standup.md
POST /v1/md/email-triage

วิเคราะห์ email queue + stress level → triage SOP

// Request body
{
  "emailCount": 218,
  "stressAware": true
}

// Response 200 → email-triage.md

ChatGPT Custom GPT setup

3 step: import schema → ใส่ key → publish

  1. 1
    เปิด ChatGPT → Create Custom GPT

    ไปที่ chat.openai.com/gpts/editor

  2. 2
    Configure → Actions → Import from URL
    https://api.klai.app/openapi.json

    เลือก Authentication = Bearer → paste klai API key

  3. 3
    เพิ่ม system prompt แนะนำ
    You have access to klai API for Peak's health data.
Always pull recent metrics before giving wellness advice.
When user asks for routines/SOPs, generate as Markdown
and offer to download via /v1/md/* endpoints.

MCP server (Claude, Cursor, etc.)

เพิ่ม klai MCP server ใน config — Claude desktop หรือ tool ที่รองรับ MCP จะใช้ได้ทันที

// claude_desktop_config.json
{
  "mcpServers": {
    "klai": {
      "command": "npx",
      "args": ["-y", "@klai/mcp-server"],
      "env": {
        "KLAI_API_KEY": "klai_sk_xxxxxxxxxxxxxx"
      }
    }
  }
}
